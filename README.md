# Gaüd Trade Edge
1. Install Python 3.11+
2. `pip install -r requirements.txt`
3. `streamlit run app.py`
4. In the sidebar, select all five CSV exports (samples are in `sample_data/`) and click Import.
5. In the Trades tab, add a setup and 20+ characters of reasoning to a trade, click Save, and watch the XP bar.
Tests: `pip install pytest` then `pytest`.
